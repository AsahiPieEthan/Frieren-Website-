# ✦ Isekai Mage — Frieren Inspired Portfolio

A cinematic, interactive personal portfolio inspired by *Frieren: Beyond Journey’s End*.  
This project blends storytelling, animation, and UI design to create a calm, immersive “magic-themed” web experience.

---

## 🌿 Overview

“Isekai Mage” is a fantasy-styled personal website where each section represents a chapter in a long journey — similar to how Frieren collects memories, spells, and moments across time.

The site is designed to feel:
- Calm and reflective  
- Story-driven rather than purely technical  
- Animated with subtle, magical motion  
- Rich in visual layering and atmosphere  

---

## ✨ Features

### 🧭 Hero Experience
- Full-screen animated hero slider
- Custom navigation bar with mobile menu
- Scroll hint, progress bar, and slide counter
- Floating floral SVG decorations for atmosphere

### 📖 Story Sections
- **About Me** — narrative-driven introduction
- **Works Gallery** — card-based project showcase with hover overlays
- **Featured Sections** — dual storytelling layouts inspired by Frieren’s journey
- **Skills / Magic System** — RPG-style skill cards

### 🎞️ UI & Effects
- Custom loader animation
- Floating music player (audio control system)
- Marquee text animation
- Scroll-based reveal animations
- Custom cursor effects (dot + ring)
- Responsive design for mobile and desktop

## Quote
- Auto-generated inspirational quotes for a dynamic and reflective experience.

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (custom animations, layout system, responsive design)
- JavaScript (DOM interactions, sliders, UI logic)
- SVG graphics (custom floral decorations)
- Audio API (music player control system)
